Keel API quick reference

A short local reference for the Keel Platform API. No network request is made.

Use the Messages API with a model name, a message array, and an optional token limit.

messages.json
{
  "model": "sonnet",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "Hello Keel" }
  ]
}

For SDKs and full reference material, see system requirements or sign in at the console.
