Power your most ambitious workflows with KEEL Agent SDK

agent.ts 
import { query } from "@keel/agent-sdk";

const agent = query({
  prompt: "Review Q3 support tickets and draft a response queue.",
  options: {
    model: "fable-5",
    allowedTools: ["Read", "Write", "Bash"],
    mcpServers: {
      metrics: { command: "node", args: ["./mcp/metrics.js"] }
    },
    permissionMode: "acceptEdits",
    maxTurns: 24
  }
});

for await (const message of agent) {
  if (message.type === "result") {
    console.log(message.result);
  }
}

Built for enterprise workflows

Security and data governance

Your prompts and outputs are never used to train KEEL models by default. Fine-grained access controls, audit logs and data residency give security teams the guardrails they expect.

◎

Scalable infrastructure

Go from a prototype to millions of requests with managed capacity, high-throughput batch APIs and rate limits that grow with your workloads. Reliability is built into every layer.

⬡

Flexible deployment

Deploy through Amazon Bedrock, Google Cloud Vertex AI or Microsoft Foundry, and choose US-only inference where compliance requires it. The same models, wherever you build.

Control cost and performance
