Keel verifies each installer's SHA-256 over HTTPS, and releases carry a Keel Ed25519 signature. That is not an operating-system code signature: these installers are unsigned, so macOS Gatekeeper and Windows SmartScreen may warn on first launch. Uninstalling never touches your ~/.keel directory.
