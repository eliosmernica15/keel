Quickstart

Start from a small, honest example

These snippets are illustrative. Run them in your own project after you have read the current API page.

JavaScript

An example shape only. This page makes no request; confirm the current contract on the Platform API page.

example.js
// Illustrative only — see /platform/api for the current contract
const response = await fetch('http://localhost:3000/api/messages', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    model: 'sonnet',
    messages: [{ role: 'user', content: 'Summarise this brief' }]
  })
});
const result = await response.json();
console.log(result);

cURL

A local example you can adapt in your own terminal. Nothing here contacts Keel.

terminal
# Illustrative only — run inside your own project
curl -X POST http://localhost:3000/api/messages   -H 'Content-Type: application/json'   -d '{"model":"sonnet","messages":[{"role":"user","content":"Hello from Keel"}]}'

Python

The same example using the standard library. Adapt it to the current API before you run it.

example.py
# Illustrative only — see /platform/api for the current contract
import json, urllib.request

payload = {
    "model": "sonnet",
    "messages": [{"role": "user", "content": "Summarise this brief"}],
}
request = urllib.request.Request(
    "http://localhost:3000/api/messages",
    data=json.dumps(payload).encode("utf-8"),
    headers={"Content-Type": "application/json"},
)
with urllib.request.urlopen(request) as response:
    print(json.load(response))

Local preview · no request made · nothing saved.
