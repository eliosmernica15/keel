System Requirements

PlatformRequirement
WindowsWindows 10 or newer, 64-bit, 4 GB RAM
macOSmacOS 12+ (Apple Silicon or Intel), 4 GB RAM
Linuxglibc 2.31+, 64-bit, 4 GB RAM (AppImage/DEB/RPM)

Keel runs locally. A model provider key is optional — a deterministic built-in fake supports offline evaluation.

Model size guide

  • Small (3B–7B, Q4): ~4–6 GB RAM, everyday tasks.
  • Medium (13B, Q4): ~8–12 GB RAM, stronger reasoning.
  • Large (30B+, Q4): 16 GB+ RAM, best quality.

First run (unsigned builds)

  1. Download the installer for your platform from /download and verify its SHA-256.
  2. Install and launch Keel. On macOS, right-click → Open the first time (Gatekeeper) because community builds are unsigned.
  3. Open Settings → Providers and add your own key, or stay offline with the built-in fake.
  4. Bind a workspace folder; Keel tools run only inside it.
