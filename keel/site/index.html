Developer

This public mirror has no backend — everything on this page renders in your browser. These endpoints exist only in the local app (keel serve):

  • GET /api/healthliveness + version
  • GET /api/providersprovider status (presence only, never key material)
  • POST /api/runstream a keel run as NDJSON
  • GET /api/fs/list?path=browse directories (names only)
  • POST /api/workdirbind agent tools to a folder
  • GET /api/settingsyour saved configuration (secret-free view)
  • POST /api/settingssave UI + provider preferences
  • GET /api/settings/exportsecret-free export
  • POST /api/fleet/providers/saveverify & store a provider key
  • POST /api/fleet/providers/cataloglive model catalog for a provider
  • POST /api/fleet/providers/removeforget a stored key
  • GET /api/fleet/skillsskills loaded on this machine
  • GET /api/fleet/connectorsMCP connectors + presets

For provider probes and MCP diagnostics run keel doctor in a terminal. The fleet console lives at /fleet on the same bridge.
