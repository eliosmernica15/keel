Connects with your favorite command line tools

Your terminal is where real work happens. Keel Code connects with the tools that power development—deployment, databases, monitoring, version control. Rather than adding another interface to juggle, it enhances your existing stack.

FAQ

You can access Keel Code with a Keel Pro, Max, or Ultra plan, a Team or Enterprise plan, or a Keel Console account. Download Keel Code and sign in with your respective Keel or Console credentials.

Keel Code can handle routine work like bug fixes and testing, and larger jobs like refactors and new features that are long-running and asynchronous. You set the direction as the architect and orchestrator, and Keel Code does the work. Describe what you want and it plans, writes code, runs tests, and opens pull requests. It can work on several tasks at once, and surface decisions you need to make for it to keep going.

Keel Code runs in your terminal and works alongside your preferred IDE and development tools without requiring you to change your workflow. Keel Code can also use command line tools (like Git) and MCP servers (like GitHub) to extend its own capabilities using your tools.

Keel Code is designed to work within limits you set. Permission modes, allow and deny rules, and hooks decide what runs with or without your approval. In auto mode, safeguards check higher-risk actions before they run and block the ones they flag as risky. Auto mode relies on classification systems and does not eliminate risk.

Keel Code works on macOS, Linux, and Windows. See full system requirements.

When used with a Keel Console account, Keel Code consumes API tokens at standard API pricing.
