Core capabilities

Cowork is your teammate for the work that fills your day.

KEEL Cowork takes on your tasks

Works directly in folders and tools you choose, and runs your task to deliver work for review. No need to copy from a chat or paste into files.

Say what, not how

Tell KEEL what you need, not how. It opens browsers for web tasks and takes over your screen only when it has to.

See the work as it happens

KEEL shows each step: the files it opens, tools it uses, and choices it makes. Follow along from anywhere, and redirect it if you need to.

Your work follows you

KEEL Cowork runs on web, desktop, and mobile and is the same KEEL, wherever you work. Start at your desk, pick it up on your phone.

KEEL works when you don't

Close your laptop, it keeps going. Schedule a task for any cadence, and it runs unattended. You come back to your deck, spreadsheet, or research.

More than one thing at a time

Big projects are split into chunks that run together. While it drafts, it researches and organizes at the same time. You review polished work.

A built-in browser for Cowork

When a task requires opening a site, reading a page, or filling a form, KEEL opens a browser in the Cowork side panel instead of yours while you keep working.

  • No installation needed.
  • Separate from your own browser, logins, and tabs.
  • Sign in once for every session, or import cookies to stay signed in to your browser (Chrome, Edge, and Firefox on macOS; Firefox on Windows and Linux).

Available in the Cowork desktop app on Pro, Max, Ultra, and Team plans. Enterprise admins manage it in Organization settings → Cowork.

FAQ

Cowork is where you hand KEEL real work. It runs on desktop, with web and mobile. KEEL works in the files and tools you choose and completes multi-step tasks from start to finish. You define the goal. KEEL figures out how to get there.

Every conversation starts as a chat. When a task needs it, KEEL uses Cowork's capabilities, with permission to read, edit, and create files you choose, so it can complete the task rather than just describe how to do it. The unified experience is rolling out across plans; until it reaches your account or organization, you'll find Cowork next to Chat.

KEEL Code is built for software engineering — writing, debugging, and shipping code. It's available as a terminal tool, desktop app, web interface, and mobile app, with integrations for GitHub and popular IDEs like VS Code and JetBrains. Cowork is built for non-coding knowledge work — research, analysis, document creation, and other multi-step tasks. It uses the same agentic approach as KEEL Code.

Yes. Start a task from your phone, and KEEL keeps working in the cloud even when your laptop is closed. Check in, redirect, or review the result from anywhere. Available in Pro, Max, Ultra, and Team plans automatically. Enterprise plans can opt in.

Computer use lets KEEL interact directly with your screen to open apps, navigate your browser, or run tools. KEEL reaches for your connectors and integrations first, falls back to your browser when needed, and only uses your screen as a last resort. This matters because using a direct integration is faster and more precise than navigating through the screen. When KEEL does interact with your screen, it is designed to ask permission before accessing each application. You can see what it's doing and can stop it at any step. Computer use is in research preview for both Cowork and KEEL Code.

Cowork can understand the following file types:

  • Documents and text: Word documents (.docx, .doc), PDF files (.pdf), Plain text (.txt), Markdown (.md), HTML (.html), JSON (.json), CSV (.csv), TSV (.tsv)
  • Spreadsheets: Excel files (.xlsx, .xls, .xlsm)
  • Presentations: PowerPoint files (.pptx, .ppt)
  • Images: Common formats like .png, .jpg, .jpeg, .gif, .svg, .webp
  • Data and config: YAML (.yaml, .yml), XML (.xml), TOML (.toml)
  • Notebooks: Jupyter notebooks (.ipynb)
  • Code files: Pretty much any programming language: Python (.py), JavaScript (.js), TypeScript (.ts), React (.jsx, .tsx), Java, C/C++, Go, Rust, Ruby, PHP, SQL, shell scripts, etc.

You can also use Connectors to view additional files.
