## 1. What runs where

```
Electron main (desktop-app/main.js)
  ├─ resolveRenderer({resourcesPath, env})  ->  unified | legacy | mirror
  ├─ spawn Python sidecar (keel.exe serve)  ->  prints http://127.0.0.1:<port>/?t=<token>
  ├─ (unified only) spawn Next standalone server.js in child env:
  │     KEEL_BRIDGE_URL=http://127.0.0.1:<port>   KEEL_BRIDGE_TOKEN=<token>
  │     HOSTNAME=127.0.0.1   PORT=<reserved loopback>   NODE_ENV=production
  └─ BrowserWindow.loadURL(token-free http://127.0.0.1:<nextPort>/)

Browser -> Next BFF /api/bridge/<path> --inject x-keel-token--> Python /api/fleet/<path>
```

Python remains authoritative. The token is **never** in a `NEXT_PUBLIC_*` var, a window URL,
`localStorage` or the loaded HTML. Legacy/mirror modes keep the exact previous behaviour
(`BrowserWindow.loadURL(http://127.0.0.1:<sidecarPort>/?t=<token>)`).

## 3. Environment variables

| Variable | Where | Value / effect |
|---|---|---|
| `KEEL_DIST_DIR` | build | **must be unset** for packaging; QA uses isolated `.next-*` trees |
| `KEEL_RENDERER` | Electron host | `unified` / `legacy` / `mirror` (case-insensitive). Invalid → fail closed. `mirror` alone is refused; use `KEEL_UI_PROFILE=mirror`. |
| `KEEL_UI_PROFILE` | Electron host | `mirror` = explicit diagnostic rollback to `site/app.html` |
| `KEEL_UI_DIR` | Electron host | explicit static UI root (needs `index.html`); honoured for `legacy`/`mirror` only, **ignored for unified** so a static dir cannot replace the Next server |
| `KEEL_RENDERER_UNIFIED_DIR` | Electron host | dev/diagnostic override for the standalone root; must contain `server.js`, `.next/static` and `public` |
| `KEEL_RENDERER_PORT` / `KEEL_RENDERER_READY_TIMEOUT_MS` | Electron host | explicit loopback port override / readiness deadline (default 30 s) |
| `KEEL_BRIDGE_URL`, `KEEL_BRIDGE_TOKEN` | Next child **only** | set by Electron from the parsed sidecar URL; read by the BFF at module load. Never `NEXT_PUBLIC_*`. |
| `HOSTNAME` | Next child | set to `127.0.0.1` by `main.js` (standalone `server.js:9` reads `HOSTNAME || '0.0.0.0'`). Earlier source set `HOST`; that defect is fixed in source but still needs a G4 socket assertion. |
| `ELECTRON_RUN_AS_NODE` | Next child **only** | set to `1`; the host runs `process.execPath` (the Electron binary) as a plain Node process, so no second runtime is shipped |
| `PORT` | Next child | OS-reserved loopback port (not `0`); one retry on early exit |
| `KEEL_TOKEN`, `KEEL_NO_BANNER` | Python sidecar | token + banner suppression (existing behaviour) |
