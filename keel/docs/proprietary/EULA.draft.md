## Clause checklist

1. Grant: personal, non-transferable right to install and run the binary on the
   user's own device; no source access; no redistribution; no sublicensing.
2. Scope: free use, local-first operation, no mandatory account, no payment.
3. Restrictions: no reverse engineering except where local law expressly
   permits; no removal of notices; no use of third-party marks in branding.
4. Third-party components: incorporated by reference from `THIRD_PARTY_NOTICES`.
5. Data: user data stays local; no Keel-operated hosted storage; no telemetry.
6. Updates: update checks are optional and disable-able; no automatic install
   without user consent.
7. Warranty/liability: "as is", to the extent permitted by law.
8. Term and termination: license ends on breach; effects of termination.
9. Contact and governing law: placeholders above.
