## Rollback (offline uninstall path, no internet needed)

Set the environment variable when launching the installed EXE:

```powershell
# legacy local renderer (previous behaviour, desktop/ui)
$env:KEEL_RENDERER=legacy ; & "C:\Program Files\Keel\Keel.exe"

# explicit site mirror diagnostic (separate surface)
$env:KEEL_UI_PROFILE=mirror ; & "C:\Program Files\Keel\Keel.exe"

# explicit static UI dir override (needs index.html)
$env:KEEL_UI_DIR="C:\path\to\desktop\ui" ; & "C:\Program Files\Keel\Keel.exe"
```

`desktop/ui`, `site/` and the PyInstaller sidecar remain inside the package as rollback assets; no source was deleted (`KEEL_RENDERER` values: `unified` / `legacy` / `mirror`; invalid values fail closed).
