## E. Path-scoped rule injected as a `nested_memory` attachment on file access

Probe: `.claude/rules/ts-rule.md` with `paths: ["**/*.ts"]`; the session then Read `sample.ts`.
The rule is NOT in the launch-time `instructions` attachment; it arrives later as a
`nested_memory` attachment whose `rendered` field is a system-reminder block.

```json
{
 "type": "attachment",
 "attachment": {
  "type": "nested_memory",
  "path": "<PROJ>/.claude/rules/ts-rule.md",
  "content": {
   "type": "Project",
   "content": "# TS rule\nAlways answer with the token RULE_TS_LOADED.\n",
   "globs": [
    "**/*.ts"
   ],
   "contentDiffersFromDisk": true,
   "rawContent": "---\npaths:\n  - \"**/*.ts\"\n---\n# TS rule\nAlways answer with the token RULE_TS_LOADED.\n",
   "displayPath": ".claude\rules\ts-rule.md"
  },
  "rendered": [
   {
    "content": "<system-reminder>\nContents of <PROJ>/.claude/rules/ts-rule.md:\n\n# TS rule\nAlways answer with the token RULE_TS_LOADED.\n\n</system-reminder>"
   }
  ],
  "renderedRole": "system"
 }
}
```
